# Contributing

Thanks for your interest in Wintainium!

This is a personal project that I'm sharing as-is, for people to clone, fork and tinker with. I'm not maintaining it for others at the moment, which means:

- **Issues are my own backlog.** They're turned on so I can plan and track work I do with Claude; the issue forms are written for that. I'm not taking feature requests from others.
- **Pull requests aren't accepted.** I'm not taking code contributions.
- **Forks are welcome.** Make it your own: add release sources, change the window, adapt it to your setup. You don't need to ask.
- **No support or update schedule.** I update it when it's useful for my own setup.
- **Security problems are the exception.** Please report them privately, as described in [SECURITY.md](SECURITY.md), not in a public issue.

## If you fork it

- Run `.\tests\Run-Tests.ps1` after changes. The suites cover status detection, every release source, downloads, checksums and add-app, and run on Windows PowerShell 5.1 and PowerShell 7.
- Wintainium is GPL-3.0. If you share a modified version, keep it under the GPL-3.0 and keep the license and copyright notices.
- Please give your fork its own name or make clear it's a fork, so people know which version they're running.
